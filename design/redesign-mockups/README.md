# Макеты редизайна Pine & Ember

Основной экран — объединённый макет по обратной связи пользователя.
Предыдущие три направления сохранены в архиве и доступны по ссылке в шапке.
Они заморожены: больше не дорабатываются и не включены в текущие проверки.
Это визуальное исследование текущего интерфейса, не новая функциональность приложения.
Рабочие `static/` и `app/` не изменены.

## Объединённый макет

- Финансы — из «Тихого леса», без изменения состава и оформления страницы.
- Сайдбар — из «Рабочего стола». Порядок: трекер → база знаний → финансы.
- Трекер — текущая доска приложения: колонки по 240 px с переносом, компактные карточки,
  цветная полоса приоритета слева, зачёркнутые завершённые задачи и прежний выбор очереди.
  Переключатель одной колонки на мобильном экране и оформление карточек из редизайна убраны.
- База знаний — текущий дизайн приложения: блоки друг под другом, карточки тем,
  раскрытие описания понятия прямо в карточке и прежние элементы редактирования.
- Единственное дополнение в БЗ — номера `01`, `02`, `03` с моноширинным шрифтом,
  приглушённым цветом и отступом 12 px из «Рабочего стола».
- Решения из «Тёплого фокуса» в новый вариант не перенесены.

## Посмотреть

Из этой директории:

```sh
npm ci
npm run dev
```

Открыть <http://127.0.0.1:5177/>. Нужен Node.js версии 20.19 или новее.
Для проверок в браузере дополнительно нужен установленный Google Chrome.

В основном макете можно переключать три раздела, выбирать ширину просмотра,
раскрывать понятия и менять выравнивание карточек тем.

В архивной галерее можно:

- переключать направления и разделы;
- сравнить три направления одного раздела друг под другом;
- посмотреть мобильную компоновку в узкой области;
- открыть отдельный макет без элементов галереи;
- открыть задачу, понятие или операции категории;
- переключить очередь, мобильный статус задач, блок или тему базы знаний;
- показать состояния расхода/дохода и RUB/BYN;
- открыть демонстрационные формы добавления и выбора периода.

Адрес сохраняет выбранные направление и раздел. Работают переходы браузера назад и вперёд.

## Архивные направления

### Тихий лес

- Финансы: баланс и две сводки, категории, отдельный график.
- Трекер: привычные пять колонок.
- База знаний: карточки тем внутри блоков.

### Рабочий стол

- Финансы: быстрый ввод первым, плотные категории.
- Трекер: список задач по статусам.
- База знаний: список тем рядом с текстом понятия.

### Тёплый фокус

- Финансы: баланс и график на первом плане, форма сбоку.
- Трекер: акцент на задачах в работе.
- База знаний: светлая область чтения на зелёном фоне.

Во всех направлениях сохранены тёмно-зелёная основа, персиковый акцент,
шрифты Outfit / JetBrains Mono и предметная структура текущего приложения.
На узком экране меняется компоновка, а не просто уменьшается весь интерфейс.
У трекера показана одна выбранная колонка со всеми пятью статусами в переключателе.

## Границы макета

Все задачи, суммы и заметки вымышлены. Запросов к API приложения нет.
Кнопки добавления и редактирования показывают демонстрацию, а не сохраняют записи.
Поля форм — визуальные компоненты: ввод и проверка пользовательских значений не реализованы.
Выбор диапазона показывает форму, но не пересчитывает демонстрационные суммы.
Перетаскивание, удаление и сохранение записей здесь не реализованы.

Финансовая сводка согласована: доходы 100 000 ₽, расходы 43 800 ₽, разница 56 200 ₽.
В списке категории «Продукты» показаны последние три операции, а не все двенадцать.

Шрифты загружаются из Google Fonts, как в текущем приложении. Если сеть недоступна,
используются системные шрифты. Других внешних запросов при просмотре нет.

## Проверки

Сначала запустить галерею в отдельном терминале, затем из этой директории:

```sh
npm run typecheck
npm run build
npm test
npm run rehearse
```

- `typecheck` — проверка TypeScript.
- `build` — отдельная сборка галереи в `dist/`.
- `test` — только 12 сочетаний основного макета, раздела и ширины: 1440, 1024, 768 и 390 px.
  Проверяются порядок навигации, структура финансов, текущая доска, компоновка БЗ,
  номера понятий, раскрытие описаний, открытие задачи и отсутствие запросов к API.
- `rehearse` — только 6 статичных кадров основного макета с проверкой Stageshow `--still --gate`
  на ширинах 1440 и 390 px. Проверка доски завершается замечаниями к исходной компоновке:
  инструмент считает перенос колонок и многострочные карточки ошибками. Они сохранены намеренно,
  поскольку редизайн доски исключён из задачи. Подробности — в `REHEARSAL.md`.

Артефакты проверок пишутся в `shots/` и не добавляются в Git.
Адрес для тестов можно переопределить переменной окружения `MOCKUP_URL`.
Подробности визуальной проверки и ограничения — в `REHEARSAL.md`.

## Файлы

- `src/main.tsx` — галерея, навигация, адаптивная сцена Stageshow.
- `src/RefinedGallery.tsx` — основной объединённый макет.
- `src/ExistingBoard.tsx`, `src/existing-board.css` — доска в текущем оформлении приложения.
- `src/ExistingKnowledge.tsx`, `src/refined.css` — текущая БЗ с нумерацией и оформление нового просмотра.
- `src/Finance.tsx`, `src/Board.tsx`, `src/Knowledge.tsx` — три раздела.
- `src/ui.tsx` — кнопки, панели, формы и диалоги.
- `src/data.ts` — демонстрационные данные.
- `src/style.css` — оформление и адаптивные компоновки.
- `kit/` — исходные компоненты Stageshow.
- `tools/` — исходные инструменты съёмки и проверки Stageshow.
- `reference/static-card/` — неизменённый исходный пример Stageshow.

Сторонние `kit/`, `tools/` и `reference/` сохранены с исходными комментариями и лицензией MIT
в `STAGESHOW-LICENSE`. Встроенные изображения брендов имеют отдельные условия использования:
см. `kit/brands/SOURCES.md`. Лицензия на код не предоставляет прав на товарные знаки.
